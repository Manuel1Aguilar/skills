# skills

Claude Code skills I use day to day.

| Skill | What it does |
|---|---|
| [`user-facing-copy`](user-facing-copy/SKILL.md) | Write or review copy (UI strings, marketing pages, social captions) so it doesn't read as AI-generated: the structural tells first, then vocabulary and punctuation, with sources. |
| [`motion`](motion/SKILL.md) | Animations and motion graphics that look directed: concept, rhythm, timing curves, camera, transitions, characters, sound, and checking your own frames. Tool-agnostic. |

## Install

```sh
git clone https://github.com/Manuel1Aguilar/skills.git
ln -s "$PWD/skills/user-facing-copy" ~/.claude/skills/user-facing-copy
ln -s "$PWD/skills/motion" ~/.claude/skills/motion
```
